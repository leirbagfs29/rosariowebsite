Como usar o editor

/Abre o menu de elementos (oração, imagem, caixa, vídeo…). Continue digitando para filtrar: /ora +Passe o mouse à esquerda de um bloco e clique no + para inserir abaixo dele. ⋮⋮Arraste para mudar a ordem dos blocos. Clique para transformar, duplicar ou excluir. ##␣No início de uma linha vira subtítulo (###␣ subtítulo menor). -␣Lista com marcadores · 1.␣ lista numerada · >␣ citação ---Separador com cruz. Ctrl+B / I / E / KNegrito · itálico · marcar · link (ou selecione o texto e use a barra). Ctrl+Z / Ctrl+YDesfazer · refazer Ctrl+DDuplicar bloco EscSeleciona o bloco inteiro (depois Delete exclui, Alt+↑↓ move). Enter ×2Dentro de caixas e orações, duas vezes Enter sai do bloco. 🖼Clique na imagem para escolher a posição (esquerda, centro, direita — o texto contorna) e o tamanho. 📋Colar um texto com vários parágrafos cria os blocos automaticamente.
